# INK & IRON 3D（墨水与钢铁）

一款基于 **Three.js (WebGL)** + **原生 ES Modules** + **Web Audio API** 打造的美式漫画风格第一人称射击（FPS）游戏。画面采用 3 阶硬切赛璐璐着色（Cel-Shading）、反向法线厚黑墨线描边（Inverted Hull）、半调网点（Halftone）与 XIII 风格三格击杀分镜，开箱即玩、完全离线运行。

## 核心特色

- **真 3D 赛璐璐美漫视觉**
  - Three.js `PerspectiveCamera` 原生高清 DPR 渲染，自适应窗口比例，支持右键机瞄平滑缩放（ADS）与冲刺动态 FOV 拉伸。
  - 所有角色、武器、油桶与道具均带厚黑墨线轮廓与程序化高清漫画贴图（砖墙、霓虹商铺、警戒钢板、通缉令、反派实验室、城市天际线）。
  - 独立 2D 特效叠加层实时投影 3D 漫画拟声词气泡（`BLAM!`、`POW!`、`HEADSHOT!`、`KABOOM!`、`BOING!`、`K.O.!`）及冲刺速度线。
- **立体战斗与真实部位爆头**
  - 3D 关节建模敌人（礼帽黑帮 `Goon`、重装猛汉 `Brute`、赛博狙击手 `Sniper`、终极 Boss `DR. HALFTONE`），头部拥有独立碰撞盒，爆头触发 `2.2x` 暴击与三格漫画连环分镜弹窗。
  - 敌人发射可见 3D 能量弹幕，可通过移动、跳跃、翻越矮木箱、踩弹跳板或带无敌帧的冲刺进行闪避。
  - 场景中分布高爆 `TNT` 油桶，支持连锁爆炸与范围清场。
- **3 把 3D 第一人称武器 + 漫画重拳**
  - `1. THE EQUALIZER (.44 左轮)`：高精度、高爆头倍率、无限备弹。
  - `2. THE BOOMSTICK (双管霰弹)`：8 弹丸近距轰击，强力后坐力与清场能力。
  - `3. ZAP-O-MATIC (科幻射线枪)`：全自动高速连射能量束。
  - `E / V 漫画重拳`：近身出拳击退敌人并造成高额伤害。
- **按局自动存档（Checkpoints）**
  - 每期关卡（Issue #1 ~ #3）自动通过 `localStorage` 按局存档。
  - 阵亡或暂停时可直接**满血重开本关**，不会退回第 1 关；刷新页面后也可在封面点击「继续存档」直接接着打。

## 快速开始

### 环境要求
- 现代浏览器（Chrome / Edge / Firefox / Safari，支持 WebGL 与 Pointer Lock）
- Node.js 18 或更新版本（启动游戏和局域网服务）

### 安装与运行

```bash
npm ci
npm run dev
```

在包含 `package.json` 的目录运行上述命令。安装依赖后也可以用 `node server.js` 启动。启动后在房主电脑的浏览器打开 [http://127.0.0.1:8080/](http://127.0.0.1:8080/)。

## iPhone 与 GitHub Pages

- 部署后，在 iPhone 的 Safari 中打开站点，点「分享」→「添加到主屏幕」。若系统显示「作为网页 App 打开」，保留该选项。建议使用支持 WebGL 2 和导入映射的新版 Safari（iOS 16.4 或更新版本）。
- 左下摇杆移动，上方按钮冲刺。滑动屏幕空白处转动视角，右侧开火和机瞄按钮也支持按住拖动瞄准。右下是跳跃、滑铲、近战和装备栏。按住手雷可拖动预瞄，松开投掷。
- 从首页或暂停菜单进入「操作设置」，可在 25%–300% 之间调节全局灵敏度。设置同时影响腰射、机瞄和狙击开镜，并保存在当前浏览器。
- GitHub Pages 提供单人战役。局域网合作和对战由房主运行 `npm run dev`，iPhone 通过房主提供的同网地址加入。
- 本地生成 Pages 产物时运行 `npm ci` 和 `npm run build:pages`，输出位于 `pages-dist/`。仓库所有者在 **Settings → Pages** 将发布来源设为 **GitHub Actions** 后，合入 `main` 的更新会由 **GitHub Pages** 工作流发布。

## 局域网联机

1. 让 2–4 名玩家连接同一 Wi‑Fi 或有线局域网。房主启动服务，从游戏封面进入「局域网联机」，输入昵称并创建「合作闯关」或「玩家对战」房间。
2. 将房间里的邀请链接发给队友。队友用浏览器打开，填好昵称并点击「加入」。也可以打开房主终端显示的局域网地址，再手动输入五位房间码。
3. 房主点击「开始游戏」，各自点击「进入战斗」锁定鼠标。联机时按 `ESC` 可释放鼠标，其他玩家可以继续战斗。

- **合作闯关**支持一起打通原有的三期关卡。伤害、道具和团队得分在玩家间同步。还有队友存活时，倒下的玩家会在 6 秒后复活。全队倒下时，房主可以重开本关。
- **玩家对战**在市中心暗巷进行自由对战。先击倒对手 10 次的玩家获胜。倒下后 3 秒复活，复活时有短暂保护。
- 同一个服务可以开多个房间。房主退出房间时，房主权限交给留在房间里最早加入的玩家。所有房间都随服务关闭而结束。

如果队友打不开页面，确认使用的是房主的局域网地址，并检查房主电脑是否允许局域网设备访问 TCP 8080。可用环境变量 `PORT` 改端口。

## 操作指南

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动走位 |
| `SPACE` | 跳跃（可跳上/翻越矮木箱，踩绿色弹跳板腾空） |
| `SHIFT` | 冲刺闪避（带短暂无敌帧与漫画速度线） |
| `鼠标移动` | 自由 3D 视角瞄准 |
| `鼠标左键` | 开火射击 |
| `鼠标右键` | 机瞄精确缩放（ADS） |
| `E` / `V` | 漫画重拳近战击退（`POW!`） |
| `1` / `2` / `3` / `滚轮` | 切换武器 |
| `R` | 装填弹药 |
| `M` | 开关 Web Audio 合成音效 |
| `ESC` | 暂停菜单（可继续、重开本关或回到第 1 期） |

## 关卡一览

1. **ISSUE #1 — DOWNTOWN ALLEY**：市中心暗巷，帮派分子与高爆油桶街区遭遇战。
2. **ISSUE #2 — THE INK FACTORY**：墨水工厂，重装敌人、赛博狙击手与双弹跳板立体混战。
3. **ISSUE #3 — DR. HALFTONE'S LAIR**：半调博士秘密实验室，三连发弹幕最终 Boss 决战。

```text
comic-fps/
├── index.html          # 游戏入口、importmap、封面与 HUD 结构

└── js/

    ├── lan.js          # 局域网大厅、连接与输入
    ├── engine.js       # Three.js 3D 场景、物理碰撞、AI 弹幕、粒子与 2D 拟声词投影
    ├── weapons.js      # 3 把 3D 武器建模、ADS 机瞄动画与近战重拳
    ├── textures.js     # 赛璐璐色阶贴图、黑墨描边工具与程序化漫画纹理
    ├── levels.js       # 3 期关卡地图、敌人配置、道具与视觉主题
    └── audio.js        # Web Audio API 零依赖合成音效引擎
```
